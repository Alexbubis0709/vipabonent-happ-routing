# VIPABONENT Happ Routing

Автоматический профиль маршрутизации для Happ.

Цель: российские домены и российские IP идут напрямую с устройства пользователя, весь остальной трафик — через VPN.

Профиль предназначен для автоматической доставки через подписку 3x-ui, чтобы конечному пользователю было достаточно отсканировать один QR-код.
